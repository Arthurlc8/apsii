# 🎂 Agenda de Aniversários

Fala, pessoal! 👋 

Esse repositório guarda a minha resolução da Lista de Exercícios 01 da faculdade. O objetivo foi sair da teoria e colocar a mão na massa com Programação Orientada a Objetos (POO) em Java, criando um sistema de gerenciamento de aniversários direto ao ponto.

## 🛠️ Stack do Projeto

* **Java** (Aplicando os conceitos de POO na veia)
* **Maven** (Para organizar a estrutura e deixar tudo no padrão)

## ⚙️ O que o sistema faz?
* Cadastra a galera informando Nome, Dia e Mês.
* Faz consultas rápidas para descobrir quem faz aniversário em uma data específica.
* Remove os cadastros pelo nome.

## 🚀 Como ver funcionando

Para testar, é só clonar o projeto e rodar a classe `Main.java` no seu IDE. Deixei o fluxo de testes todo pronto por lá, printando as inserções, buscas e exclusões direto no console!
